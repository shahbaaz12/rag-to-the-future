# Lesson data

These are copies of the learning datasets supplied in `C:/a/pproj/AI/zPracticeAndDel/rag/doc`. Original files remain unchanged.

- `smallStories/*.txt`: ten fables used by conversational RAG.
- `products/*.txt`: ten Nexa product guides used by hybrid retrieval.
- `products2/Hierarchical_Product_Catalog.json`: twenty sample products, twenty-six variants, and ten subcategory groups.

Only text companions and the catalog JSON are required by these lessons. The reference directory's PDFs and generated vector databases are not dependencies of this version. Product names, specifications, prices, and troubleshooting instructions belong to the supplied demonstration dataset.
