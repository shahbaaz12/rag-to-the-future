Professor’s field note · Optional story

I open the service bay in 2015. Individual switches work, but the machine needs a route between them. Together, we’ll connect operations, carry their state, and make room for a person to decide.

Each lesson uses its own everyday example. You can follow every notebook without reading the story.

What we are building

Connect two simple steps, explore four connection patterns, draft an email, and look up leave records. Then compare travel options with a tool loop, remember a student's topics, stream a recipe, and pause a refund for approval. Each example gives the next graph feature a practical purpose.

Run each notebook from the top. Lessons 1, 2, and 8 run locally without an API key. The model examples use our existing Groq setup and GROQ_API_KEY in the local .env file.
