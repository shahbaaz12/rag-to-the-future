What we are building

Start with two ordinary Python functions. Add different paths, connect a model, then let the application execute tools. Once that flow is clear, add conversation memory, streamed output, and a pause for a person’s decision.

Run each notebook from the top. Lessons 1, 2, and 8 run locally without an API key. The model examples use our existing Groq setup and GROQ_API_KEY in the local .env file.
